# Examples

Each example below is a page in the [example app](https://github.com/billymaulana/nuxt-actions/tree/main/example) in the nuxt-actions repository. Every page here shows the server action and the component that calls it, runs the page live right where you read it, and links to the full source on GitHub.

<ExampleIndex />

## Run the examples locally

```bash
git clone https://github.com/billymaulana/nuxt-actions
cd nuxt-actions
pnpm install
pnpm dev:prepare
pnpm --filter nuxt-actions-example dev
```

Then open `http://localhost:3000` and pick an example, or open the [live demo](https://nuxt-actions-demo.vercel.app) without installing anything.
