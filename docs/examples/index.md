# Examples

Each example below is a page in the [nuxt-actions-example](https://github.com/billymaulana/nuxt-actions-example) app. Every page here shows the server action, the component that calls it, and links to the full source on GitHub and to a StackBlitz project you can edit in the browser.

<ExampleIndex />

## Run the examples locally

```bash
git clone https://github.com/billymaulana/nuxt-actions-example
cd nuxt-actions-example
pnpm install
pnpm dev
```

Then open `http://localhost:3000` and pick an example, or [open the whole app in StackBlitz](https://stackblitz.com/github/billymaulana/nuxt-actions-example) without installing anything.
